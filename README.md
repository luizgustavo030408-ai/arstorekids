# AR Kids — site

Site de apresentação da AR Kids, loja de moda infantil em Boa Vista - RR.
Desenvolvido por Vendora Labs (instagram.com/vendora_labs).

## O que tem aqui

- `index.html`: o site completo. Todas as fotos e a logo já estão DENTRO deste arquivo, então ele funciona sozinho.
- `img/`: cópia das fotos recortadas e da logo, para usar em posts ou editar o site depois.
- `favicon.png` e `apple-touch-icon.png`: ícones da logo.
- `vercel.json`: configuração da Vercel.

## Publicar no GitHub + Vercel

1. Descompacte o zip.
2. No GitHub, abra o repositório, apague os arquivos antigos e use **Add file → Upload files** para enviar o conteúdo desta pasta. O `index.html` precisa ficar na raiz (primeira tela do repositório), não dentro de outra pasta.
3. Na Vercel: Framework Preset **Other**, Root Directory **./**, e Build Command, Output Directory e Install Command **vazios**.
4. Deploy. Depois de cada novo upload no GitHub, a Vercel atualiza sozinha.
